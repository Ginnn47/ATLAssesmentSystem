# Blackbox Testing ATL Assessment System

Folder ini berisi panduan singkat untuk menyiapkan dan menjalankan blackbox testing pada backend Django dan frontend Playwright.

Automation test yang sudah disiapkan:

- Backend Django: `atlBackend/tests/`
- Frontend Playwright: `atl-framework/tests/`

Jalankan dependency install secara manual dari terminal lokal kamu, lalu gunakan checklist pada `01_Setup/INSTALL_BLACKBOX_TOOLS.md`.
